# cai-dat-openclaw-windows-mac-linux

Cài đặt OpenClaw trên Windows, macOS và Linux với gateway local, Token Codex mặc định tại `https://codex.anhlaptrinh.vn/v1`, model `GPT-6.1-sol` khi người dùng cung cấp API key, chỉ dùng bốn model `GPT-6.1-sol`, `GPT-6-terra`, `GPT-6-luna`, `GPT-6-astra`; không tự bật DeepSeek.

Phiên bản cài đặt được ghim `openclaw@2026.10.6` (cập nhật ngày 2026-10-24), không tự dùng `latest`. Node.js phải đạt `>=24.22.1 <25 || >=26.12.1`; installer từ chối Node không tương thích và kiểm tra đúng phiên bản OpenClaw trước khi cấu hình Gateway.
