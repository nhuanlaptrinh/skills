# cai-dat-openclaw-windows-mac-linux

Cài đặt OpenClaw trên Windows, macOS và Linux với gateway local, Token Codex mặc định tại `https://codex.anhlaptrinh.vn/v1`, model `GPT-6.1-sol` khi người dùng cung cấp API key, chỉ dùng ba model `GPT-6.1-sol`, `GPT-6.1-terra`, `GPT-6-astra`; không tự bật DeepSeek.

Phiên bản cài đặt được ghim `openclaw@2026.11.2` (cập nhật ngày 2026-11-09), không tự dùng `latest`. Nếu OpenClaw đã có, installer cập nhật lên đúng phiên bản này; nếu chưa có, installer cài mới. Node.js phải đạt `>=24.16.0 <25 || >=26.1.0`; installer từ chối Node không tương thích và kiểm tra đúng phiên bản OpenClaw trước khi cấu hình Gateway.
