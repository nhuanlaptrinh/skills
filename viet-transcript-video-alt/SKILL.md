# Viet Transcript Video ALT

## Core Goal

Create spoken Vietnamese transcripts for short social videos that sound like Anh Lap Trinh: practical, direct, friendly, a little blunt, and rooted in real work.

Default target: 30 seconds, about 85-110 Vietnamese words. If the user gives another duration, adjust the word count:

- 15 seconds: 40-55 words.
- 30 seconds: 85-110 words.
- 45 seconds: 120-155 words.
- 60 seconds: 165-210 words.

## Workflow

1. Identify the target viewer and one concrete pain.
2. Compress the raw material into one main promise, not many promises.
3. Write for voiceover first: short sentences, natural pauses, no essay paragraphs.
4. Start with a real work scene or blunt observation.
5. Show the before/after: manual work vs AI assistant/workflow.
6. Name the tool/course only after the viewer recognizes the pain.
7. End with one direct CTA or belief line.

## ALT Voice Rules

- Write in Vietnamese.
- Use "anh em" naturally when speaking to a broad audience.
- Prefer everyday work words: viec that, may tinh, tin nhan, bao cao, file Excel, email, ra lenh, lam thay, vuong dau go do.
- Keep the teacher voice practical: "cu ung dung vao viec that", "chua ngon thi sua tiep", "dung co gong thu cong mai".
- Avoid glossy corporate AI copy.
- Do not promise perfect automation, guaranteed income, or effortless results.
- Do not overload the transcript with feature lists.
- Keep emojis out of the transcript unless the user explicitly asks for a social caption version.

## Recommended Structure

For a 30-second transcript:

1. Pain hook: 1-2 sentences.
2. Specific scene: 1-2 sentences.
3. Shift: introduce the AI assistant/workflow.
4. Benefit: 2-3 concrete actions it can do.
5. CTA: one direct closing sentence.

For HeyGen + HyperFrames videos, optionally split output into:

- `avatar_intro`: 4-6 seconds, direct-to-camera hook.
- `continuation`: remaining voiceover for motion graphics.
- `full_transcript`: joined text.

## OpenClaw Positioning

When writing about OpenClaw:

- Frame it as creating a team of AI assistants on the user's own computer.
- Contrast clearly: ChatGPT mainly answers in chat; OpenClaw receives commands and performs actions on the computer.
- Mention real workflows: Zalo/Viber/email, browser, Excel, Word, PDF, reports, fanpage, customer care, data lookup, content posting.
- Treat each assistant like a new employee: let it run first, then improve instructions, data, and workflow.
- Close with practical support language: "vuong dau minh go do cho", "gui workflow cua anh em qua", or "dang ky OpenClaw".

## Output Style

Unless the user asks for more, return only the finished transcript in a fenced text block. If useful, add a short note with estimated duration.

Do not add production notes, scene direction, captions, hashtags, or title options unless requested.
